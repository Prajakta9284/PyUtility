# Changelog

All notable changes to PyUtility will be documented in this file.

# [0.1.2] - 2026-10-18

# Added
- Automated quality checks using GitHub Actions.
- Automated release build and package validation.
- Utility decorators for caching, retries, and argument validation.
- Lazy data pipeline functions for filtering, mapping, and chunking.
- Context managers for files, SQLite connections, and JSON configuration.
- Plugin registration using a metaclass.
- JSON serialization and deserialization utilities.
- Unit, integration, and property-based tests.
- Sphinx documentation.
- Example application demonstrating library features.
- Retail sales analysis example.

# Improved
- Package metadata includes the README description.
- Windows integration tests handle SQLite connections safely.
